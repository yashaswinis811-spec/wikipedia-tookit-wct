# Wikipedia Toolkit - WCT - Open Source Day

This repository contains 3 tools built for WCT challenges using Wikipedia data.

### Challenge 2: Wiki Structure Visualizer
Input: Article Name -> Processing: Extract People, Org, Places, Topics -> Output: Display Result
Tool helps visualize structure of Wikipedia article.

### Challenge 3: WikiWeak Finder
Analyzes article quality based on content length, sections, images, references.
- Red = Weak, Orange = Moderate, Green = Rich
- Displays bar chart ranking weakest articles
- Helps editors find articles needing improvement.

### Challenge 4: WikiFact Check
Compares Infobox value vs Article Text value.
Example: Infobox says 15 May 1980 vs Text says 16 May 1980 -> Flags as "Possible mismatch for human verification"

### Tech Stack
Python, ipywidgets, pandas, matplotlib
Platform: Kaggle Notebooks
